- אזור אישי פעיל: מועדפים, הכרטיסים שלי, הזמנות קודמות ופרטים אישיים.
- שני כרטיסים דיגיטליים לדוגמה.
- אייקון הקטגוריות הועבר לצד ימין של שש הקוביות.
- בלוק WhatsApp / ניוזלטר בעמוד הבית.
- אייקון Placeholder לכל כותרת קרוסלה.
- עמוד מופע חוזר תמיד לטאב "מועדים".
- חלק עליון של בחירת מושבים ממשיך את עמוד המופע.
- תהליך רכישה מעודכן: אורח/משתמש קיים, קופון, דמי טיפול, פרטי מזמין, תשלום ואישור.
- הוסרו אזכורים לקהל סגור.
