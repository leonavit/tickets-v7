# Tickets V6

אב־טיפוס סטטי אינטראקטיבי (HTML / CSS / JS) למערכת כרטיסים — בעברית, RTL.  
מיועד לאימות זרימות משתמש, מבנה מסכים ופונקציונליות לפני עיצוב UI סופי.

## התחלה מהירה

| קובץ | תפקיד |
|------|--------|
| [`intro.html`](intro.html) | מסך הקדמה לסקירת UX |
| [`index.html`](index.html) | דף הבית — וריאציה 1 |
| [`index2.html`](index2.html) | דף הבית — וריאציה 2 (הירו מלא) |
| [`index3.html`](index3.html) | דף הבית — וריאציה 3 (חיפוש מתחת לכותרת) |

פתיחה מומלצת: `intro.html` → בחירת דף בית.

## מה יש בפרויקט

### ניווט ומסכים
- SPA עם ניתוב ב־hash: בית, כל המופעים, עמוד מופע, בחירת מושבים, סל, רכישה, אזור אישי, יצירת קשר ועוד
- תפריט מובייל (המבורגר) — מסך מלא כהה עם קישורים לבנים
- לחיצה על «אזור אישי» / אייקון משתמש מובילה לאזור האישי
- תפריט נפתח (hover) לכרטיסים, הזמנות ופרופיל

### דף הבית
- שלוש וריאציות פריסה
- חיפוש (מיקום, תאריך, קטגוריה, חופשי)
- קרוסלות מופעים עם חיצי chevron מעודכנים ומצב disabled בקצוות
- קטגוריות, מועדפים, בלוק WhatsApp / ניוזלטר

### עמוד מופע ורכישה
- טאבים: מועדים / מידע
- שורות מועדים רספונסיביות (כולל ספירה לאחור למכירה מוקדמת)
- זמינות נמוכה → פופאפ תור (לחיצה על רקע ריק מדלגת לבחירת מושבים)
- אזלו כרטיסים → רשימת המתנה
- תהליך רכישה: סל, קופון, פרטי מזמין, תשלום, אישור

### בחירת מושבים (אולם)
- מפת אולם עם במות: ימין / מרכזית / שמאל + גושים
- מסנן מחיר / נגישות, זום, מסך מלא
- סיכום בחירה (פאנל צד / תחתית במובייל)
- מבנה האולם נשמר במסכים צרים (גלילה/זום במקום ערימה)

### מצב הדגמה
- מתג «מצב הדגמה» עם סמן מוגדל
- הדגשת אזורים + תפריט מעבר בין וריאציות דף הבית
- תמיכה במסך מלא (כולל z-index / העברת סמן)

### אזור אישי
- הכרטיסים שלי (PDF / WhatsApp)
- מועדפים, הזמנות קודמות, פרטים אישיים
